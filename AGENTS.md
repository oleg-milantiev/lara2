# Инструкция для Агентов (LLM)

Этот проект развернут в Docker-окружении. При работе с кодом и выполнении команд следуйте данным правилам.

## Команды и пути

- **Запуск команд:** Все команды (artisan, phpunit, composer) должны запускаться через Docker Compose:
  `cd /root/lara && docker compose exec -it php [команда]`
- **Корневая директория в контейнере:** `/var/www/lara`
- **Корневая директория в хост-системе:** `/root/lara2/lara` (для файлов Laravel)

## Структура проекта

- **Модели:** `app/Models/Manufacturer.php`, `app/Models/Product.php`, `app/Models/Price.php`.
- **Индексы:** В миграции `create_initial_tables` добавлены индексы для оптимизации отчетов (по датам, категориям и композитные индексы для цен).

- **Тесты:** `tests/Unit/`.
